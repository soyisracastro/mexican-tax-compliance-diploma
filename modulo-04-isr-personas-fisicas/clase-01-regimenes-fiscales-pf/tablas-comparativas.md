## Glosario de Términos Clave

| Término | Definición operativa |
|---|---|
| **Acumulación por flujo de efectivo** | Principio por el cual una persona física reconoce el ingreso solo cuando lo cobra efectivamente, no cuando lo factura. |
| **Asimilados a salarios** | Ingresos que, sin ser técnicamente sueldos, se tratan fiscalmente como tales por decisión legal u opción del contribuyente (Art. 94 fraccs. I-VII). |
| **Base gravable** | Monto sobre el cual se aplica la tarifa para calcular el impuesto. En PF es ingresos − deducciones − pérdidas anteriores − deducciones personales (en anual). |
| **Buzón tributario** | Canal digital del SAT para notificaciones legales, obligatorio para todos los regímenes salvo 605. |
| **CFDI** | Comprobante Fiscal Digital por Internet. La factura electrónica mexicana. Requisito para deducciones. |
| **Cuota fija (en tarifa)** | Componente fijo del ISR correspondiente a cada escalón de la tarifa progresiva, que se suma al impuesto marginal calculado sobre el excedente. |
| **Deducción ciega** | Deducción de 35% del ingreso bruto, sin necesidad de comprobantes, aplicable en arrendamiento (Art. 115 LISR). |
| **Discrepancia fiscal** | Procedimiento del Art. 91 LISR por el cual el SAT presume ingresos gravados cuando las erogaciones superan los ingresos declarados. |
| **DIOT** | Declaración Informativa de Operaciones con Terceros. Obligación mensual del régimen 612 para reportar proveedores. |
| **e.firma** | Firma electrónica avanzada, certificado digital del SAT. Obligatoria para RESICO, 612, 606, 625. |
| **EFOS** | Empresas que Facturan Operaciones Simuladas. Contribuyentes publicados en listado Art. 69-B CFF. |
| **Flujo de efectivo** | Ver "Acumulación por flujo de efectivo". |
| **Impuesto marginal** | En tarifa progresiva, impuesto resultante de aplicar el porcentaje del escalón al excedente sobre el límite inferior. |
| **Ingresos exentos** | Ingresos gravables por naturaleza pero que la ley libera del pago de ISR bajo condiciones (Art. 93). |
| **Ingresos gravables/acumulables** | Ingresos sobre los que se calcula ISR. |
| **Opinión de cumplimiento** | Documento del Art. 32-D CFF que certifica que el contribuyente está al corriente. Requisito para RESICO. |
| **PTU** | Participación de los Trabajadores en las Utilidades. Derecho laboral con implicación fiscal. |
| **Pagos provisionales** | Anticipos a cuenta del ISR anual, obligatorios mensualmente en la mayoría de regímenes. |
| **Pago definitivo** | Mecanismo donde la retención o pago mensual constituye el impuesto total del ejercicio, sin declaración anual. Aplica a RESICO (2026) y Plataformas con ingresos ≤$300K. |
| **Régimen fiscal preferente (REFIPRE)** | Jurisdicciones con baja imposición, cuyos ingresos deben ser acumulados por residentes mexicanos. |
| **Residencia fiscal** | Calidad del contribuyente según Art. 9 CFF (casa habitación o centro de intereses vitales en México). |
| **RESICO** | Régimen Simplificado de Confianza. Régimen opcional con tasas de 1% a 2.5% para PF con ingresos ≤$3.5M. |
| **Retenedor** | Persona (física o moral) obligada por ley a retener impuesto al momento de pagar. |
| **Subsidio para el Empleo** | Crédito fiscal que reduce el ISR retenido a trabajadores de menores ingresos. Monto actualizado anualmente por decreto. |
| **Tarifa progresiva** | Esquema de ISR donde la tasa aumenta conforme sube la base gravable, en escalones sucesivos. |
| **UMA** | Unidad de Medida y Actualización. Referencia económica para cálculos fiscales. Actualizada anualmente por INEGI. |
| **ZLFN** | Zona Libre de la Frontera Norte. Franja fronteriza con régimen fiscal especial (tasas IVA e ISR reducidas). |

## Calculadora Express — Fórmulas Operativas

### Fórmula de retención mensual de sueldos

```
Retención = [(Ingreso − LI) × Tasa%] + Cuota_Fija − Subsidio_Empleo
```

### Fórmula de pago provisional (612)

```
Pago_Provisional = ISR_Periodo − Pagos_Anteriores − Retenciones
donde:
ISR_Periodo = [(Base_Acumulada − LI×N) × Tasa%] + Cuota_Fija×N
y:
Base_Acumulada = Σ(Ingresos) − Σ(Deducciones) − PTU − Pérdidas
N = número de meses transcurridos en el periodo
```

### Fórmula RESICO mensual

```
ISR = Ingresos_Cobrados_Sin_IVA × Tasa_Escalón
Pago_Neto = ISR − Retención_PM(1.25%)
```

### Fórmula arrendamiento con deducción ciega

```
Base = Ingresos − (Ingresos × 35%) − Predial_Pagado
ISR = Tarifa_Art_152(Base)
Pago = ISR − Retención_PM(10%)
```

### Fórmula plataformas digitales (opción definitiva)

```
ISR_Definitivo = Ingresos_Plataforma × Tasa_Actividad + Ingresos_Directos × Tasa_Actividad
```
